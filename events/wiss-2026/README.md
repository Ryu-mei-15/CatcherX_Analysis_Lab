# WISS 2026

WISS 2026のデモ発表として採択された予稿と，予稿で扱うCatcherXの進塁阻止機能を紹介するページです．デモ発表は審査あり・論文査読なしの区分です．会議は2026年12月9日から11日まで苗場プリンスホテルで開催されます．個別の発表日時は確定後に反映します．

## 公開内容

- 投球前の走者配置と進塁開始
- 捕手の捕球，持ち替え，塁送球
- 内野手のベースカバー，捕球，タッチ
- 走者到達との比較によるアウト／セーフ判定
- 返球，一塁牽制，二盗・三盗阻止，ダブルスチール
- 方向意図と三次元誤差を残す送球アシスト
- 投稿予稿で示した未来ビジョン
