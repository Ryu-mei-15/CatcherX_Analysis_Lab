# EC2026

EC2026で発表した「CatcherX: 捕手の認知-運動過程の循環に着目したVRシミュレータ」のページ，公開データ，発表資料，分析コード，評価フォームを収録します．

- Webページ：このフォルダ直下
- ページ専用JavaScript：`js/`
- 変換前ログ：`data/raw/`
- 公開用JSON：`data/public/`
- 論文・スライド・ポスター：`materials/`
- データ変換・検証：`analysis/`
- Google Apps Script：`backend/apps-script/`
- 運用手順：`docs/`

旧来のルート直下URLには互換用の転送HTMLを残しています．新しいリンクは`events/ec2026/`以下を使用してください．
