# CatcherX Research Data

「CatcherX: 捕手の認知-運動過程の循環に着目したVRシミュレータ」の研究データ公開・分析サイトです．EC2026公開版論文，主要な集計結果，プレイログ可視化，第3フェーズの配球分析，二元配置分散分析，NASA-TLX／SUS回答収集を一つのサイトにまとめています．

本サイトはHTML，CSS，JavaScriptを中心とした静的サイトです．標準尺度の認証と回答保存に限り，Google Apps Scriptと非公開Googleスプレッドシートを使用します．

## 主な機能

- EC2026公開版論文（IPSJ-EC2026006）のブラウザ内閲覧
- 予稿に掲載した制球誤差，ミット補正量，誤差低減率の公開
- プレイヤ，球速，投球コースによるプレイログの絞り込み
- 捕球誤差，平均ミット補正量，制球誤差との相関の可視化
- プレイヤと球速を要因とする二元配置分散分析
- 第3フェーズにおける参加者別の配球順序，球種，コース，球速，打者反応，捕球結果の閲覧
- 打者反応後の球種変更・コース変更に関する正確確率検定
- NASA-TLXおよびSystem Usability Scale（SUS）の固定ID・OTP認証付き回答収集

## ローカルでの起動

リポジトリのルートでHTTPサーバを起動します．JSON取得やPDF表示を行うため，HTMLファイルを直接開かずHTTP経由で閲覧してください．

```sh
python3 -m http.server 8000
```

ブラウザで次を開きます．

```text
http://localhost:8000/
```

## データの再生成

### ログ可視化用データ

`convert.py`は`DataCourse`内のCSVから，座標差，ミット補正量，制球誤差を計算して`data.json`を生成します．pandasが必要です．

```sh
python3 -m pip install pandas
python3 convert.py
```

現在の`convert.py`では`DATA_DIR`をローカルパスで指定しています．別の配置で実行する場合は，実行環境の`DataCourse`ディレクトリへ変更してください．

### 第3フェーズ公開用データ

`convert_phase3.py`は標準ライブラリだけで動作します．`DataBreak/*_1_2.csv`から，全65球の参加者別時系列と，各参加者の第1球を除く59遷移を生成します．

```sh
python3 convert_phase3.py
```

生成物は`phase3-data.json`です．

### 第3フェーズ検定の再現

```sh
python3 analyze_phase3.py
```

次の4項目について検定値を再計算します．

1. 直前球からの球種変更
2. 直前球からのコース変更
3. 次球種の選択（ストレート／変化球）
4. 次コースの高さ（高め／真ん中／低め）

主要検定には固定周辺度数に基づくFisher–Freeman–Halton正確確率検定を使用します．同一参加者内の反復を考慮する感度分析として，参加者内で打者反応ラベルを置換する100,000回の置換検定も実行します．乱数seedは固定しています．

## 統計解析の位置付け

### 第3フェーズ配球分析

打者反応を「見逃し」「ハーフスイング」「空振り」に分類し，その後の配球更新との関連を探索的に確認します．球種変更・コース変更の反応間事後比較には2×2 Fisher正確確率検定とHolm補正を使用します．参加者6名・59遷移の小標本であるため，非有意を「影響がない」ことの証明として扱いません．

### 二元配置分散分析

`anova.html`では，軸方向ごとの符号付き捕球誤差を目的変数とし，「プレイヤ」と「球速」を要因とするType II二元配置分散分析をブラウザ内で実行します．出力する項目は次の3つです．

- プレイヤの主効果
- 球速の主効果
- プレイヤ×球速の交互作用

投球コースは分析要因ではなく，解析対象を絞り込む条件です．交互作用が有意な場合は主効果だけで単純化せず，条件別平均のグラフと併せて解釈します．p値は差の大きさを表す値ではなく，p ≥ .05も「差がない」ことの証明ではありません．

## NASA-TLX／SUS回答収集

`evaluation.html`は，固定参加者IDと研究担当者が発行した8桁OTPが一致した場合だけ回答フォームを表示します．認証・保存は`apps-script/Code.gs`が処理します．

評価フォーム用の固定IDには数字だけの正の整数を使用し，必要な人数分を登録できます．これは公開済みログの`Player 1`，`Player 2`等の識別子とは別に管理します．

- 固定参加者IDはCSVから登録・更新可能
- OTPは60分間有効で，認証成功時に使用済みとなる
- OTPの一致時だけ30分間有効な署名付きトークンを発行
- OTPはハッシュ化して非公開シートに保存
- 認証失敗は15分間に5回まで
- 実施日はブラウザ入力ではなく，サーバ受信時の日本時間で確定
- IDごとに回答可能な実験条件を指定
- 同じ参加者ID×実験条件の重複回答を拒否
- NASA-TLXとSUSの値域検証・スコア計算をサーバ側でも実施
- 個別回答と参加者IDは公開せず，`approved = TRUE`かつ各条件3名以上の集計だけを公開

NASA-TLXはRaw TLXと15対の一対比較を用いる重み付き方式に対応しています．SUSは奇数項目を「回答値 − 1」，偶数項目を「5 − 回答値」として合計し，2.5倍して0–100のスコアへ変換します．SUSの値は百分率ではありません．

実験当日のOTP発行，再発行，回答確認，デプロイ更新を含む操作方法は[`GAS_OPERATION_GUIDE.md`](GAS_OPERATION_GUIDE.md)を参照してください．バックエンドの仕様と初期導入の説明は[`apps-script/README.md`](apps-script/README.md)に記載しています．接続先の`/exec` URLは[`evaluation-config.js`](evaluation-config.js)で設定します．

平文OTP，スプレッドシートID，`OTP_PEPPER`，`SESSION_SECRET`は公開リポジトリへ追加しないでください．

## EC2026公開版PDFについて

`paper.html`はPDFビューアのツールバーと直接ダウンロード導線を表示しません．ただし，Webブラウザへ配信したPDFの保存，開発者ツールからの取得，画面撮影を技術的に完全防止することはできません．本ページはダウンロード操作を抑制する表示であり，DRMではありません．

掲載中のPDFは情報処理学会の情報学広場で公開された`IPSJ-EC2026006`です．公式の書誌情報と配布条件は[情報学広場のレコード](https://ipsj.ixsq.nii.ac.jp/records/2011336)を参照してください．

## 表記と研究データ上の注意

- 日本語表記は情報処理学会の予稿に合わせ，「プレイヤ」「ユーザ」「サーバ」「インタフェース」などに統一します．
- 画面上の参加者表記には匿名化IDを使用し，氏名などの直接識別子を掲載しません．
- 公開結果は参加者数，試行数，提示順序などの制約を含む探索的分析として解釈してください．
- 研究データや集計値を更新した場合は，予稿記載値との対応関係と再生成手順も更新してください．
